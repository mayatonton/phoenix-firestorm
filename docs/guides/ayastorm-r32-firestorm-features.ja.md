# AYAstorm r32 に取り込んだ Firestorm の6機能

r32 統合ブランチに実装した機能の操作ガイドです。現時点の検証はソースと設定・UI 定義の静的確認までです。ビルドと実機確認は未実施です。

| 機能 | 操作と仕様 |
| --- | --- |
| インベントリの名前をコピー | 通常一覧またはギャラリーでアイテムかフォルダーを1件選び、右クリックして **名前をコピー** を選びます。名前をテキストとして貼り付けられます。リンクではリンク先の名前を使います。リンク切れの場合はインベントリに残っている名前を使います。 |
| アウトフィットの並べ替え | **アバター → アウトフィット** の並べ替えメニューで **アルファベット順** または **新しい順** を選びます。新しい順はフォルダー直下のアイテムやリンクのうち、最も新しい作成日時を使います。同じ日時や日付不明の場合は名前順です。従来の「お気に入りを上に並べ替える」はどちらの順序にも併用でき、既存の設定も引き継ぎます。 |
| アバター読み込み中の雲の色 | **環境設定 → Firestorm → 特殊機能** で開始色と終了色を指定します。色は雲の更新時に反映されます。透明度は読み込んだ雲の設定に従います。AYAstorm 側で読み込み雲を非表示にしている場合、色を指定しても雲は表示されません。 |
| 編集ハンドルの色 | **環境設定 → Firestorm → 編集色** で X・Y・Z 軸と座標表示の背景の色を選びます。移動・回転・拡縮の軸と、アバターのジョイント編集の移動・回転に反映されます。 |
| macOS Dock から別に起動 | 起動中の AYAstorm の Dock アイコンを右クリックし、**ビューアを別に起動** を選びます。同じアプリの別プロセスを開きます。別プロセスにも **環境設定 → 高度な設定 → 複数のビューアを許可** の既存設定が適用されます。 |
| お気に入りの着用物や HUD のフォルダー整理 | **アバター → お気に入りの着用物やＨＵＤ** を開きます。上段でフォルダーを選び、隣のボタンで作成・名称変更・削除ができます。選択したフォルダーに装着物をドラッグするか、着用物リストの右クリックから **お気に入りフォルダーに追加** を選びます。お気に入りのリスト内では **お気に入りフォルダーへ移動** も使えます。 |

## お気に入りフォルダーの保存

- フォルダーとリンクは従来のインベントリ内の `#Wearable Favorites` 配下に保存します。フォルダーの作成先はその直下です。
- **すべてのお気に入り** は従来のリンクとフォルダー内のリンクをまとめ、同じ装着物を1行に表示します。この表示で削除ボタンを使うと、一覧で選んだ装着物のお気に入りリンクをまとめて外します。フォルダーを選択中は、その一覧で選んだリンクが削除対象です。
- 移動時は移動先のリンクを確認してから元のリンクを外します。フォルダーの削除では、読み込み済みのフォルダー内にリンクと削除可能なサブフォルダーだけがあることを確認します。元の装着物はインベントリに残ります。
- フォルダー名はインベントリの名前形式に合わせ、表示可能な半角英数字と記号を使います。`/`、`\`、`|` は入力できません。
